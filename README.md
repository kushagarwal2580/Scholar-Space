  # Scholar Space: The Ultimate Student Study Companion App
</div>

Scholar Space is an open-source student planner and study companion app designed to help you organize learning materials and figure out how to track study hours effectively. Solve your productivity challenges by keeping course notes, tracking study sessions with built-in timers, and seamlessly syncing all your data to Google Drive.

## 🚀 Key Features for Student Productivity
- **Cloud Synchronization**: Securely backup and sync your library, profile, and app state to Google Drive to seamlessly switch between devices.
- **Study Timers & Stopwatches**: Track your study sessions accurately. Includes persistent background notifications so you always know how long you've been working.
- **Material Library**: Keep your study materials organized. Easily manage course notes, textbooks, and audio recordings.
- **Built-in File Viewer**: View your PDFs and listen to audio recordings directly within the app without needing third-party viewers.
- **Profile Management**: Customize your student profile with notes and statuses.

## 🛠️ Tech Stack & Open Source Frameworks
Scholar Space is an open-source Android application built with modern development practices:
- **Programming Language**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3 Design)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Local Database**: Room Database for offline-first data persistence
- **Cloud Integration**: Google Drive API for remote sync and backup
- **Concurrency**: Kotlin Coroutines and Flows

## 📱 Requirements
- **Android Device**: Minimum OS Android 8.0 / API Level 26
- **Google Account**: Required for Drive Sync and Authentication features
