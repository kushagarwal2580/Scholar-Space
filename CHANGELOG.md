# Changelog

## Recent Updates

### Features & Improvements
* **Audio Note Recorder**: Improved recording functionality and user interface.
* **File Viewer Enhancements**: 
  * Removed extra top and bottom spacing/info cards for a cleaner, full-screen document viewing experience.
  * Fixed scrollbar jumping issues when navigating near the top or bottom of documents.
  * Enabled smooth one-finger scrolling/panning when zoomed into PDFs and documents.
* **Google Drive Integration**: Added a dedicated page and improved connection for browsing and importing files from Drive.
* **Haptics**: Added vibration feedback across the app for better interactive response.

*Note: This log is maintained to track recent development progress for GitHub releases.*
